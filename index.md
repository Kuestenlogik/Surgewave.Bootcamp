# Surgewave Bootcamp

Welcome to the Surgewave Bootcamp — your hands-on learning path for mastering Kuestenlogik.Surgewave, a high-performance event streaming platform.

- .NET 10 SDK
- An IDE (Visual Studio, VS Code, or Rider)
