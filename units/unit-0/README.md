# Unit 0: Introduction

Welcome to the Surgewave Bootcamp! Before diving into code and operation, let's understand what Surgewave is and why you might want to use it.

## Learning Objectives

By the end of this unit, you will:

- Understand what message streaming is and why it matters
- Know what Surgewave is and how it compares to alternatives
- Recognize the benefits Surgewave brings to your architecture
- Be ready to start building with Surgewave

## Who Is This For?

This bootcamp is designed for:

- **Developers** building distributed applications
- **Architects** evaluating messaging solutions
- **Teams** considering Kafka alternatives
- **Anyone** curious about modern event-driven systems

## No Prerequisites

This unit requires no prior knowledge of:
- Kafka or message brokers
- Distributed systems
- Event-driven architecture

We'll cover all the background you need!
